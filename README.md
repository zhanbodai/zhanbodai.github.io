# zhanbodai.github.io

Source for my personal website, [zhanbodai.github.io](https://zhanbodai.github.io/). It is a Jekyll site hosted on GitHub Pages.

Pages are in `_pages`, projects are in `_portfolio`, and the layout and styles are in `_layouts/plain.html` and `assets/css/site.css`.

The repository started from the [AcademicPages](https://github.com/academicpages/academicpages.github.io) template, which is released under the MIT license.
