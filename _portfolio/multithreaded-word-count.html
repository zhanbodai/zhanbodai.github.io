What I built

  1. Program
    Counts words per file and in total across .txt.gz files with a pool of threads and locks, and writes the table as CSV, Parquet or Arrow.
  2. Comparing AI-generated code
    Wrote a specification, had three Gemini models generate code from it, and compared the results with a pytest suite.
  3. Benchmarks
    Timed the program across thread counts on 256 generated files with standard and free-threaded Python 3.13, and compared how fast each output format reads back: Parquet reading only one column and Arrow through memory mapping.
