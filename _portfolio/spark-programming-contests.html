What I built

  1. Data
    Loaded DeepMind's CodeContests dataset from HDFS into Hive tables, bucketed the solutions table by language, and joined it with lookup views to decode ID columns.
  2. Spark APIs
    Answered the same question with the RDD API, the DataFrame API and Spark SQL, and read query plans to see when bucketing removes a shuffle.
  3. Caching
    Timed the same aggregation before and after caching a filtered DataFrame.
  4. Natural-language queries
    Wrote a function that sends a question and the table schemas to Gemini, extracts the generated SQL, and runs it on Spark.
  5. Machine learning
    Trained a Spark MLlib decision-tree pipeline to estimate Codeforces ratings where they were missing, and compared train and test R² for tree depths from 1 to 30 to show overfitting.
