What I built

  1. Data layer
    Two identical gRPC servers that load City of Madison address data and return addresses for a ZIP code in sorted order.
  2. HTTP layer
    Three Flask servers that alternate requests between the data servers, switch to the other server after a failure (up to five attempts), and report which server answered.
  3. Caching
    An LRU cache of three ZIP codes in each HTTP server, so it can still answer some requests when both data servers are down.
  4. AI-assisted coding
    Built the project through a series of short prompts in Aider with Gemini 2.5 Flash, and reviewed the generated code.
