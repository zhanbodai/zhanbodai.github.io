What I built

  1. SQL
    Joined and filtered loan records in MySQL to 426,716 rows with loan amounts between $30,000 and $800,000.
  2. HDFS
    Wrote the result to HDFS as Parquet with 2x replication and 1 MB blocks, and used the WebHDFS API to count the blocks stored on each DataNode.
  3. County files
    Answered average-loan queries by county, saving each county's rows as a smaller Parquet file and reusing it on later requests. A benchmark script timed first and repeated requests and plotted the difference.
  4. Fault tolerance
    County files have one replica, so after a DataNode was killed the server caught the read error and rebuilt the lost file from the main file, which has two.
