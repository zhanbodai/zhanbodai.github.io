What I built

  1. Schema
    Designed a table with station ID as the partition key, date as the clustering key, a static name column, and a user-defined type for daily minimum and maximum temperatures, with 3x replication.
  2. Loading
    Parsed the fixed-width NOAA station file with Spark to select Wisconsin stations, and inserted them into Cassandra.
  3. Service
    Implemented gRPC calls that return the table schema, look up a station name, record temperatures, and return a station's highest temperature.
  4. Fault tolerance
    Used prepared statements with fixed consistency levels: writes at ONE, so sensors can upload while any replica is up, and reads at THREE, so reads include every acknowledged write (R + W > RF). When a node was down, reads fell back to ONE and flagged the result. Tested by killing a node.
