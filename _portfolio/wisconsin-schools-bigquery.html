What I built

  1. Setup
    Ran Jupyter on a Compute Engine VM and uploaded the raw Parquet file to a Cloud Storage bucket with PyArrow.
  2. Pipeline
    Wrote three Dataform actions: one builds a table of Wisconsin counties from a public BigQuery dataset, one loads the schools file from Cloud Storage, and one joins them geographically to place each school in a county. Uploaded and compiled them from Python and checked the dependency graph.
  3. Queries
    Used BigQuery pipe syntax to find counties with at least two cities that each have three or more public high schools, estimated how many runs of that query fit in the free tier, and found the nearest public high school to each public middle school in Dane County.
