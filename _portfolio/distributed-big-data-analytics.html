What I built

  1. Data pipeline
    A Spark (PySpark) and Hive pipeline on a distributed HDFS cluster for analyzing large datasets. I used bucketing and caching to speed up queries.
  2. Machine learning
    A Spark MLlib decision-tree pipeline that predicts missing values in dataset features.
  3. Natural-language queries
    An integration with the Gemini API that converts natural-language questions into Spark SQL that runs on the cluster.
  4. Fault tolerance
    Microservices built with gRPC and Docker, using Parquet columnar storage to reduce I/O, with automated recovery logic for data-node failures.
